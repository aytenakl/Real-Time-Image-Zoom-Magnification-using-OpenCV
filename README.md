# Real-Time-Image-Zoom-Magnification-using-OpenCV
## 📌 Description
A real-time computer vision project that captures live video from a camera and provides an interactive zoomed view of a selected region. The system uses OpenCV for image processing, cropping, resizing, and real-time frame display.

## 🚀 Features
- Real-time camera streaming
- Image region selection and magnification
- Live zoom preview
- Real-time image processing using OpenCV
- Simple and efficient implementation

## 🛠️ Technologies Used
- Python
- OpenCV
- NumPy

## ⚙️ How It Works
1. Capture frames from the webcam.
2. Select a region of interest (ROI).
3. Crop the selected area.
4. Resize the cropped region to create a zoom effect.
5. Display the magnified area with the original camera feed.
